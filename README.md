# Условие
Дано число N (N<1000). Написать программу, которая по запросу пользователя выведет последнюю или первую цифру введенного числа.
# Алгоритм 
1. Начало программы.
2. Ввод числа N (N < 1000).
3. Ввод выбора пользователя y (1 - первая цифра, 2 - последняя цифра).
4. Проверить условие (y == 1).
5. Если условие истинно (нужна первая цифра):
   - Проверить условие (N >= 100).
   - Если истинно: вывести N / 100 (трехзначное число).
   - Если ложно: проверить условие (N >= 10).
     - Если истинно: вывести N / 10 (двузначное число).
     - Если ложно: вывести N (однозначное число).
6. Если условие ложно (y != 1), проверить условие (y == 2).
7. Если условие (y == 2) истинно (нужна последняя цифра):
   - Вывести N % 10 (остаток от деления на 10).
8. Если условие (y == 2) ложно:
   - Вывести сообщение "Ошибка" (неверный ввод).
9. Конец программы.

# Реализация
```c
﻿#include<stdio.h>
#include<locale.h>
int main() {
	setlocale(LC_ALL, ".UTF8");
	int x,y;
	printf("Введите чилсо до 1000 ");
	scanf_s("%d",&x);
	printf("цифра 1 - первая цифра числа, цифра 2 последняя цифра числа \n");
	scanf_s("%d",&y);
	if (y == 1) {
		if (x >= 100) {
			printf("первая цифра - %d\n", x / 100);
		}
		else if (x >= 10) {
			printf("первая цифра - %d\n", x / 10);
		}
		else {
			printf("%d\n",x);
		}
	}
	else if (y == 2) {
		printf("последня цифра - %d\n", x % 10);
	}
	else {
		printf("Ошибка\n");
	}
	system("pause");
	return 0;
}
```
